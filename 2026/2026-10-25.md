## 메모리 증설, 메모리 스왑, 디스크 증설 등
- 홈 서버의 램 증설 4GB -> 12GB
  - 재부팅 시 윈도우로만 부팅되는 이슈
    - BIOS 설정에서 UEFI and CSM OS 설정하고 재부팅 -> ubuntu 선택
  - <img src="../resources/images/ram%20upgrade_4gb_12gb.png" width="600"/>
- 메모리 스왑 관련
  - 12GB로 메모리 증설 후 `Swap used`가 0.0%으로 표시 (Grafana)
  - 램이 넉넉하면 os kernel이 swap을 사용하지 않음
    - swap 개념 자체가, 램이 부족할 때 사용 빈도가 낮은 데이터들을 disk의 swap 영역으로 내리는 것(swap-out)
    - 필요할 때 다시 메모리로 불러움(swap-in)
  - 아래 명령어로 스왑 상태 확인 가능
  ```bash
    free -h
    swapon -s  # 혹은 swapon --show
  ```
- 디스크 용량 늘리기 (미할당 파티션 추가 할당)
  ```bash
    # 디스크 상태 확인
    lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
    sudo vgs

    # 200기가 추가 (미할당된 파티션에서)
    sudo lvextend -r -L +200G /dev/ubuntu-vg/ubuntu-lv
    df -h /
  ```
- 우분투 볼륨 표시 방식
  ```bash
    ls -l /dev/ubuntu-vg/ubuntu-lv /dev/mapper/ubuntu--vg-ubuntu--lv
    # LVM 방식: /dev/ubuntu-vg/ubuntu-lv 
    # device-mapper 방식: /dev/mapper/ubuntu--vg-ubuntu--lv
  ```

- `Chat`은 한도가 닳지는 않지만, 작업을 시키는 경우 개별적인 한도가 닳아버림(Pro 사용을 못하게 되고, 한 단계 낮은 모델들만 사용 가능)
  - 그런데, 여기에서 사용량이 0이 된 것은 0이 되고서야 알 수밖에 없음 (사용량이 100%에서 줄어들지 않음)
- `Work`나 `Codex`로 넘어가야 `2026-10-25` 기준 Frontier에 있는 `GPT-6.1 Sol Astra`를 사용할 수 있고
  - 이 때 사용량 감소를 확인할 수 있음
- Codex reset을 자주 해주기 때문에, https://opentherank.com/codex-reset/ 에서 지난 reset 내역을 볼 수 있음
  - 가끔 초기화 쿠폰도 주니까 잘 챙길 것.
